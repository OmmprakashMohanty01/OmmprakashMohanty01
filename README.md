## 🚀 About Me

I am an **AI & Full-Stack Developer** specializing in bridging the gap between cutting-edge artificial intelligence and robust, scalable backend systems. My expertise lies in designing and deploying intelligent products that solve real-world problems. 

* **🧠 Core Focus:** Retrieval-Augmented Generation (RAG) pipelines, LLM orchestration, semantic search, and AI-driven automation workflows.
* **⚙️ System Architecture:** Building high-performance backends using **FastAPI** and **Django**, integrated with dynamic **React** frontends.
* **👁️ Computer Vision:** Developing intelligent tracking and re-identification systems using YOLO, OpenCV, and deep learning architectures.
* **🌱 Currently Learning:** Advanced distributed systems, multimodal AI models, and optimizing ML inference at scale.
* **🤝 Open Source:** Actively contributing to AI tools and open to collaborations on impactful, intelligent automation platforms.
